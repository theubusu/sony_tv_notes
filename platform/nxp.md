# NXP-based TVs

Some (EU model) Sony TVs relased in 2009 and 2010 were based on NXP CPU's and the software platform developed by and used in **Philips** TV's. How this exactly came to be is a pretty interesting mystery.   
The firmware file is the exact same `2SWU3TXV` .upg format as used in those TVs, and the main software binary still has the name "philips". 

As this platform is not developed by Sony and also easily findable(many plain dumps) and firmware can be decrypted, it is out of the scope of interest.

### Platforms:
- EX2N, 2009 - M4(5500)/M5(5600)/M6(3600)/M7(57x0,5550,5650) fw
- AZ1N, 2010 - M8 fw
