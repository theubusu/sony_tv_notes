# Other Platforms

List, timeline mapping of other platforms of interest by year,region + notes. Note that this is NOT a complete list, many mapping is missing, espacially for Japan. And some series are excluded because of no interest

America mapping based on OSS release:   
https://web.archive.org/web/20120717055235/https://products.sel.sony.com/opensource/source_tv.shtml   
Update file mentions from avsforum.com

Europe mapping based on bulletin TV_Keypartslist_v46.xls (listing all TV models released in 2007 and beyond [..]):   
http://televid-sib.org/index.php?PHPSESSID=vivda2fje0p3li7netsg1itlup&topic=131399.msg269962#msg269962

Japan mapping based on this useful chart website:   
https://avchart.g3.xrea.com/lctv/lctv07so.html   
And update releases:   
https://www.sony.jp/bravia/update/

## 2004
### SP1 (America)
Based on ATI Xilleon 226

### SF1EG (Japan)
See `SF1EG`, for TVs with EE+GS  
Based on EMMA2HL   
Dumped

## 2005
### MIX5 (America)
Based on ATI Xilleon 226   
Firmware update file name(s): `sony_dtv_upgrade.d05`, `sony_mix_uc_upgrade.c05`.    
Downloads are lost to time.

## 2006
### FIX (America)
Based on ATI Xilleon X240H, NAND=16MB, 128KB NOR   
Firmware update file name(s): `sony_dtv_upgrade.d06`, `sony_dtv_data.s06`, `sony_chassis_download.sc06m`, `sony_dtv_data.u06`.     
Downloads are lost to time.

## 2007
### WAX3 (America)
Based on Xilleon X242, NAND=16MB, 128KB NOR

### FIX2 (America)
Based on EMMA2TH, NAND:2x64M=128M(?), 2Mbit NOR   
Firmware file name is like `sony_dtv/001F0101_00160000.bin`, same format as later TVs. Could be an interesting one, but sadly all downloads are lost to time.

### FL1 (America)
Used in XEL-1, based on Xilleon X242

### FIX2 (Europe)
Based on EMMA2TH, running RTOS (`non-linux.md`)

### WAX3 (Europe)
Based on EMMA2LR, running RTOS (`non-linux.md`)

### WAX3 (Japan)
Used in KDL-J3000/J5000, uses `BJ` board with EMMA2TH, see `WAX3JP`   
Dumped

### Unnamed2 (Japan)
No known name, used in KDL-V3000/V5000/W5000/X5050/X5000/X7000

### FL1 (Japan)
Used in XEL-1, based on EMMA2TH

## 2008
### MA2/F (America)
Based on Xilleon X244

### EX1/EZ1 (America)
Ex. XBR6,XBR7 series   
Based on Xilleon X245, OneNAND 64MB, RAM DDR2 64MB   
Firmware file is `sony_dtv_packageXXXX.p08`, the format is as in `tool/sony_pkg.py`(big endian), main data is encrypted.

### FL1E (Europe)
